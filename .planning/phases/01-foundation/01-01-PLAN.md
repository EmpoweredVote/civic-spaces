    2. Create the first migration `supabase/migrations/20260327000000_current_user_id.sql`:
       ```sql
       -- Create civic_spaces schema
       CREATE SCHEMA IF NOT EXISTS civic_spaces;

       -- Helper function: resolves current user from external JWT
       CREATE OR REPLACE FUNCTION civic_spaces.current_user_id()
       RETURNS text
       LANGUAGE sql
       STABLE
       AS $$
         SELECT auth.jwt() ->> 'sub';
       $$;

       -- Grant usage on schema to authenticated role
       GRANT USAGE ON SCHEMA civic_spaces TO authenticated;
       ```

    3. Create `src/lib/supabase.ts`:
       ```typescript
       import { createClient } from '@supabase/supabase-js'

       const supabaseUrl = import.meta.env.VITE_SUPABASE_URL
       const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY

       export const supabase = createClient(supabaseUrl, supabaseAnonKey, {
         accessToken: async () => {
           return localStorage.getItem('ev_token') ?? ''
         },
       })
       ```
       This client injects the accounts.empowered.vote Bearer token (stored in localStorage by the Auth Hub redirect flow) into every Supabase request. Do NOT use `global.headers.Authorization` — the `accessToken` callback is the current recommended approach for Supabase JS v2.

    4. Create `.env.example` documenting all required env vars:
       ```
       # Civic Spaces Supabase project
       VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
       VITE_SUPABASE_ANON_KEY=your-anon-key

       # Slice Assignment Service (services/slice-assignment/.env)
       SUPABASE_URL=https://YOUR_PROJECT.supabase.co
       SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
       ACCOUNTS_JWKS_URL=https://kxsdzaojfaibhuzmclfq.supabase.co/auth/v1/.well-known/jwks.json
       ACCOUNTS_ISSUER=https://kxsdzaojfaibhuzmclfq.supabase.co/auth/v1
       ACCOUNTS_API_URL=https://accounts.empowered.vote
       ```

    5. Install the Supabase JS client: create a minimal `package.json` at root if not present, then `npm install @supabase/supabase-js`.
