  <action>
    **1a. Create `src/lib/validators.ts`:**
    - Use Zod v4 (`import { z } from 'zod'`)
    - IMPORTANT: Zod v4 breaking change — use `z.object()` (not `z.strictObject()` for form schemas), and `error:` instead of `message:` for custom error messages
    - Export `createPostSchema`: `{ title: z.string().min(1).max(200), body: z.string().min(1).max(10000) }`
    - Export `editPostSchema`: `{ body: z.string().min(1).max(10000) }` (title is not editable after creation)
    - Export inferred types: `CreatePostInput`, `EditPostInput`

    **1b. Create `src/hooks/useProfile.ts`:**
    - Export `useProfile(userId: string | null)` hook
    - Uses `useQuery` with key `['profile', userId]`
    - Queries: `supabase.from('connected_profiles').select('user_id, display_name, avatar_url, tier, is_suspended, account_standing').eq('user_id', userId).single()`
    - Returns `{ profile: ConnectedProfile | null, isLoading: boolean }`
    - `enabled: !!userId`
    - `staleTime: 5 * 60 * 1000` (profile data changes rarely)

    **1c. Create `src/hooks/useCreatePost.ts`:**
    - Export `useCreatePost(sliceId: string)` hook
    - Uses `useMutation` from TanStack Query v5
    - Mutation function: `supabase.from('posts').insert({ slice_id: sliceId, user_id: userId, title, body }).select().single()`
    - Note: user_id is needed in the insert because RLS WITH CHECK validates it matches current_user_id()
    - Get userId from useAuth hook (passed as param or imported)
    - **Optimistic update:**
      - `onMutate`: Cancel outgoing feed queries, snapshot current cache, insert a temporary PostWithAuthor at the beginning of the first page
      - The temporary post has a generated UUID (crypto.randomUUID()), the current user's profile data, current timestamp, and reply_count: 0
      - Return the snapshot for rollback
    - `onError`: Restore snapshot from context, show error (console.error for now — toast can be added later)
    - `onSettled`: Invalidate feed queries to get authoritative data from server
    - Query key for invalidation: `['feed', sliceId]`

    **1d. Create `src/hooks/useEditPost.ts`:**
    - Export `useEditPost()` hook
    - Uses `useMutation`
    - Mutation function: `supabase.from('posts').update({ body: newBody }).eq('id', postId).select().single()`
    - Note: The DB trigger `enforce_edit_window` handles edit_history append and the 1-hour window check. The client just sends the new body.
    - `onError`: If error message contains 'edit_window_expired', show a specific message ("Edit window has expired — posts can only be edited within 1 hour")
    - `onSettled`: Invalidate feed queries
    - The hook also exports a helper: `isWithinEditWindow(createdAt: string): boolean` — returns true if the post's created_at is within 1 hour of now. Used by UI to show/hide edit button.

    **1e. Create `src/hooks/useDeletePost.ts`:**
    - Export `useDeletePost()` hook
    - Uses `useMutation`
    - Mutation function: `supabase.from('posts').update({ is_deleted: true }).eq('id', postId)`
    - Note: This is a soft delete. The RLS policy allows UPDATE on own posts.
    - `onMutate`: Optimistically remove the post from the feed cache (or mark it as deleted in-place)
    - `onError`: Restore cache
    - `onSettled`: Invalidate feed queries
  </action>
