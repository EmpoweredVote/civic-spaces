    **1a. Create `src/hooks/useThread.ts`:**
    - Export `useThread(postId: string | null)` hook
    - Two separate queries managed together:
      1. Post query: `useQuery` with key `['post', postId]` — fetches the single post with author profile
         - `supabase.from('posts').select('*').eq('id', postId).single()` then separate profile fetch
      2. Replies query: `useInfiniteQuery` with key `['replies', postId]` — fetches replies with cursor pagination
         - Page size: 20 replies
         - Order: `created_at` ascending (oldest first), then `id` ascending for tiebreaker
         - Query: `supabase.from('replies').select('*').eq('post_id', postId).order('created_at', { ascending: true }).order('id', { ascending: true }).limit(20)`
         - Cursor pagination: for subsequent pages, `.or(`created_at.gt.${cursor.created_at},and(created_at.eq.${cursor.created_at},id.gt.${cursor.id})`)` (ascending cursor — opposite of feed)
         - After fetching replies, batch-fetch author profiles for all unique user_ids (same pattern as useFeed)
    - Return: `{ post: PostWithAuthor | null, replies: ReplyWithAuthor[], fetchMoreReplies, hasMoreReplies, isLoading, error }`
    - The replies are returned as a flat list with `parent_reply_id` intact — the component will handle nesting

    **1b. Create `src/hooks/useCreateReply.ts`:**
    - Export `useCreateReply(postId: string)` hook
    - Uses `useMutation`
    - Input: `{ body: string, parentReplyId?: string }` (parentReplyId for level-2 replies)
    - Mutation function: `supabase.from('replies').insert({ post_id: postId, user_id: userId, body, parent_reply_id: parentReplyId ?? null }).select().single()`
    - `onSettled`: Invalidate both `['replies', postId]` and `['feed']` (to update reply_count on PostCard)
    - Optimistic update: Add the reply to the local reply cache with temporary UUID, current user profile, and current timestamp
    - On error: Roll back optimistic reply, show error

    **1c. Create `src/components/InformUpgradePrompt.tsx`:**

    - Props: `isOpen: boolean`, `onClose: () => void`
    - Renders a small modal/dialog overlay:
      - Heading: "Join the conversation"
      - Body: "Create a Connected account to post, reply, and participate in your civic community."
      - Primary button: "Create Connected Account" — links to `https://accounts.empowered.vote/register?tier=connected` (opens in new tab)
      - Secondary button: "Not now" — calls onClose
    - Backdrop: semi-transparent dark overlay, click to close
    - Accessible: focus trap, escape to close
